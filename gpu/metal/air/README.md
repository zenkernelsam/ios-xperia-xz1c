# AIR frontend for iOS16

The retained `reference/` sources are BSD-2-Clause/MIT code from ios_sagit at898998cf1b74ea103e0c16d6dc0016822d8d644b. Their original bytes and notices are kept; reproducibility/air-reference.json binds each file. The translator uses LLVM's exported C API, not Apple C++ object layouts. LLVM declarations remain a local dependency underdeps, with their Apache-2.0 WITH LLVM-exception notices.

Compiler.h defines a frontend-only Entry/reflection contract. materialize_air_sources.py builds an isolated copy with that interface. No reference kernel JIT selector or compiled shader registration is imported into the current SweetScatter service. LLVM16Compat.h supplies typed-pointer queries, exact mask/atomic handling and legacy module optimization through target-exported entry points. Unknown semantics return compilation errors. Host forced-legacy tests and iOS16 cache symbol audits are separate from GPU acceptance.

ESSLTarget.h adapts the translator's declared GLSL430 compute interface to the actual GLES3.1 target, using an explicit bounded local size and highp arithmetic. MetalCompute.inc parses raw AIR or an MTLB v2/FAT AIR64 container, checks each AIR SHA and declared stage, creates actual library/function/pipeline objects, and records a standard compute encoder operation. The native queue uses metal_compute.c on a dedicated robust Mesa context with the original Metal buffer's shared pages; it retains those pages through the actual submit and cache synchronization.

v729/r8's actual22 samples passed the authored MTLB/bitcode add_seven kernel twice on the original buffer. The first64 words change by7 each dispatch;16 guard words stay unchanged. Every sample has160 complete checked words and32 guard checks, with current-owned GPU fences, callbacks and final backing accounting0. Original GLES/Surface/readonly tests still pass. This proves that compute path for the admitted fixture; system Metal discovery, function constants and general application shaders, texture/render and complete UI remain pending. See docs/AIR-COMPUTE.md.
